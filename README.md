# Okazje z upadłości

Katalog ofert z licytacji komorniczych, upadłości firm i aukcji poleasingowych w Polsce: koparko-ładowarki, minikoparki, busy, wywrotki, auta i narzędzia.

- Strona: `index.html` (GitHub Pages), dane w `data/`.
- Dane aktualizuje 3× dziennie GitHub Actions (`.github/workflows/przeglad.yml`) z Claude Code według `AGENT.md`. Wymaga sekretu repozytorium `CLAUDE_CODE_OAUTH_TOKEN` (z polecenia `claude setup-token`). Ręczne uruchomienie: zakładka Actions → „Przegląd okazji” → Run workflow.
- Oznaczenia „Obserwuj” i „Odrzuć” zapisują się tylko w przeglądarce osoby, która je klika.

Ceny pochodzą z ogłoszeń. Szacunki ceny rynkowej są orientacyjne. Syndyk i komornik sprzedają rzeczy w stanie, w jakim są, bez gwarancji.
